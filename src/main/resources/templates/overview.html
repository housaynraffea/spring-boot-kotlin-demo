Overview

This page shows an overview of what is implemented in this website. Currently, this Spring Boot website has:
- 5 thymeleaf pages (6 if you count the redirect page after the 'Contact'-page)
- A POST-form (accessible here)
- fragments for a navigation bar and a footer
- CSS-styling
- Two APIs (tasks, student-attendance)
- th:each/th:if (this page)
